# Rejo Thomas — Personal Portfolio Website

A full-stack personal portfolio website built to showcase my academic projects, 
created as an MCA student to demonstrate both frontend and backend development skills.

🔗 **Live Site:** https://portfolio-website-rejothomas.vercel.app  
🔗 **Backend API:** https://portfolio-backend-5i8c.onrender.com/projects

## Tech Stack
- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Backend:** FastAPI (Python), SQLAlchemy
- **Database:** SQLite
- **Deployment:** Vercel (frontend), Render (backend)
- **Version Control:** Git & GitHub

## Features
- Fully responsive personal portfolio website
- Projects section fetched dynamically from a live database via a REST API
- Loading state while backend wakes from free-tier sleep
- Downloadable resume (PDF)
- Contact links (Email, GitHub, LinkedIn)

## Project Structure
This project uses a separate frontend/backend architecture:
- Frontend repo: this repository
- Backend repo: https://github.com/rejothomas1/portfolio-backend

## Running Locally

Clone the repository:
\`\`\`bash
git clone https://github.com/rejothomas1/portfolio-website.git
cd portfolio-website
\`\`\`

Install dependencies and run:
\`\`\`bash
npm install
npm run dev
\`\`\`

Visit `http://localhost:3000`
